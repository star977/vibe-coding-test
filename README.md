# mdnsscan

网络资产测绘 CLI。给定 IP 网段与端口范围，采集范围内设备**主动声明**的服务信息，
含深度标识——型号、固件版本、管理地址等设备自报字段。

> 这不是端口扫描器。输出中的端口不是探测出来的，是设备在服务定位记录里自己报的。

## 快速开始

```bash
go build -o mdnsscan .
./mdnsscan --cidr 192.168.1.0/24 --ports 1-65535
```

无需 root 权限。Go 1.22+ 即可构建。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--cidr` | 必填 | 待测绘网段，如 `192.168.1.0/24` |
| `--ports` | `1-65535` | 端口**过滤**范围。也接受单端口简写 `--ports 5000` |
| `--timeout` | `2s` | 单个地址的总时间预算 |
| `--concurrency` | `256` | 并发探测数，默认值使 /24 可一批打完 |

## 实现要点

完整设计、数据契约与 59 条验收标准见 [DESIGN.md](DESIGN.md)。三个关键点：

**端口范围是过滤器，不是扫描范围。**
设备的自我介绍里自带端口号，流程是「先拿到全部服务 → 再按端口范围筛」。

**深度标识全量透传，不硬编码键名。**
不同厂商的字段各不相同，代码不维护任何键名白名单，收到什么输出什么，
顺序、大小写、重复键一律不动。这是深度能否达标的唯一判据。

**双通道探测。**
主通道对网段内每个地址单播询问；兜底通道发一次全网广播，
捕获那些只监听广播、不响应单播的精简实现设备，其结果再用网段过滤。
广播通道不可用时自动降级为纯单播。

## 已知问题

设备自报值本身可能含逗号（实测 `model=Mac17,3`、`cn=0,1,2,3` 极为常见），
与用作分隔的逗号存在歧义。因题目示例同样以逗号连接，
判断参考实现存在相同歧义，故选择保真原样输出，不做转义。详见 DESIGN.md §10。

## 使用声明

本工具仅供在**已获授权的网络**中进行资产盘点使用。
它只向 `--cidr` 指定范围发包，不主动出网、不上报任何数据。
